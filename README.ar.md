# فيديو-بابليش — Video-Publish

اداة احترافية لجدولة ونشر المحتوى لصناع تيك توك: خطط للفيديوهات وادِر مكتبتك وانشر في الموعد — بمساعدة الذكاء الصناعي (Gemini).

## المميزات

- 📅 تقويم محتوى: جدولة فيديوهات تيك توك مسبقا
- 🎬 ادارة مكتبة الفيديو (رفع وتنظيم واعادة استعمال)
- 🤖 عناوين وافكار بالذكاء الصناعي (Gemini API)
- 📊 لوحة احصائيات لصناع المحتوى
- 🔐 صفحات الخصوصية والشروط جاهزة
- ⚡ React 19 و Vite و Tailwind مع خادم Express وقابلية النشر على Vercel

## التشغيل محليا

المتطلبات: Node.js. ضع `GEMINI_API_KEY` في `.env.local`.

```bash
npm install
npm run dev      # خادم التطوير
npm run build    # بناء الانتاج
npm run preview  # معاينة البناء
npm run lint     # فحص الانواع
```

## التقنيات

React 19 و Vite 6 و Tailwind 4 و Express 4 و @google/genai و TypeScript.
